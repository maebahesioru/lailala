# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it via [GitHub Security Advisories](https://github.com/maebahesioru/lailala/security/advisories/new).

We will respond within 48 hours and work to resolve the issue as quickly as possible.

Please do not disclose security issues publicly until we have had a chance to address them.
